SYSTEM DESCRIPTION
------------------
Services provided:
Demo Corp provides a SaaS platform that helps customers collect, map, and review SOC 2 compliance evidence, and generates audit-ready reports for their CPA firm.

System boundaries:
The system boundary includes the Demo Corp web application, API backend, and database, all hosted in a single AWS region (us-east-1). It excludes customer-owned infrastructure and any third-party systems Demo Corp integrates with (GitHub, AWS, Jira, Google Workspace) but does not operate.

Components:
Infrastructure: AWS (EC2, RDS Postgres, S3). Software: a Java/Spring Boot API, an Angular web application, and a Python AI microservice for evidence-to-control mapping suggestions. People: a 12-person engineering and security team. Procedures: documented change-management, incident-response, and access-review procedures (see Policies). Data: customer-uploaded evidence artifacts and compliance metadata, encrypted at rest and in transit.

Subservice organizations:
Amazon Web Services, Inc. (cloud infrastructure hosting) and GitHub, Inc. (source code hosting for customer-authorized integrations). Both maintain their own SOC 2 Type II reports, available on request.

Complementary user-entity controls:
Customers are responsible for: (1) maintaining the confidentiality of their own user credentials and API tokens configured in Demo Corp integrations; (2) promptly notifying Demo Corp of any suspected unauthorized access to their account; (3) configuring appropriate access roles for their own team members within the platform; and (4) reviewing and confirming AI-suggested evidence mappings rather than relying on them as final compliance determinations.

Significant changes during the period:
Migrated the risk register and control-exception tracking features to production during the observation period. No changes to the production AWS account structure, encryption approach, or access-control model occurred during this period.
